DOC-FULL-NR V19.0 STABILIZED CLASSROOM FLOW
==========================================

ชุดนี้รวมงานตั้งแต่ระบบหัวหน้าห้องจนถึงระบบกำหนดเวลาส่งและ Attendance Gate

1. Admin แต่งตั้ง/ยกเลิกหัวหน้าห้องได้จากหน้ารายชื่อนักศึกษา
2. ในแผงสอนทีละหน่วย Admin แก้เวลา Digital ได้ตรงการ์ดหน่วย
3. กำหนดได้ทั้งวัน/เดือน/ปี/เวลา และระยะเวลาเป็นชั่วโมง
4. มี preset 1,2,3,6,12,24,48,72,168 ชั่วโมง และกรอกเองได้
5. Admin เปลี่ยนเวลาได้ตลอดหลังเปิดหน่วย
6. เปิด/ปิดเงื่อนไขเช็คชื่อหัวหน้าห้องต่อหน่วยได้
7. ถ้าเปิดเงื่อนไข นักศึกษาที่ยังไม่ผ่านเช็คชื่อของวันนั้นจะเปิด/บันทึกร่าง/ส่ง Digital ไม่ได้
8. Backend มี Trigger บังคับซ้ำอีกชั้น ไม่พึ่ง Frontend อย่างเดียว
9. เมื่อ Digital หมดเวลา ระบบเดิมยังเปลี่ยนไปใช้ Paper ส่งย้อนหลัง
10. ปุ่มและไอคอนในแผงหน่วยถูกขยายและจัด layout ใหม่เป็นโทนเขียว-ขาว

Production Supabase migration ของ V19 ถูก apply แล้วในโปรเจกต์ DOC-FULL-NR-UNIVERSAL
