DOC-FULL-NR V19.3 — GRADEBOOK 17-UNIT + MANUAL SCORE CONTROL
==============================================================

สิ่งที่เปลี่ยนใน V19.3
- ยืนยันหน่วยงานทางการ 17 หน่วยต่อรายวิชา
- คะแนนใบงาน 17 งานเฉลี่ยรวมเป็น 40 คะแนน
- จิตพิสัย 20 คะแนน
- กลางภาค 20 คะแนน
- ปลายภาค 20 คะแนน
- รวม 100 คะแนน
- ตัดเกรดอัตโนมัติ: 80=4, 75=3.5, 70=3, 65=2.5, 60=2, 55=1.5, 50=1, ต่ำกว่า 50=0
- แสดง ผ่าน/ไม่ผ่าน ในตารางรวมคะแนนห้อง
- Admin ปรับจิตพิสัย 0–20 ได้รายบุคคล
- Admin เพิ่ม/ลดคะแนนดิบกลางภาคและปลายภาคได้จากหน้ารวมคะแนน
- การปรับคะแนนถูกบันทึก Audit Log
- Export Excel / Print เพิ่มคอลัมน์ เกรด และ ผล
- คง UX/UI Responsive V19.2 และระบบเดิมทั้งหมด
