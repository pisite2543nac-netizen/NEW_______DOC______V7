# V16.2 Grade Report

## Output
The printed/downloaded grade report follows the uploaded `อล2.xlsx` visual structure:

1. ภาคเรียน + ปีการศึกษา
2. รหัสวิชา + ชื่อวิชา
3. ตารางสรุปเท่านั้น:
   - ลำดับ
   - รหัสนักเรียนนักศึกษา
   - ชื่อ-สกุล
   - กลุ่มเรียน
   - จิตพิสัย (20)
   - ภาระงาน (40)
   - กลางภาค (20)
   - ปลายภาค (20)
   - รวม (100)

Header uses a light-blue fill with black borders, designed for A4 landscape.

## Admin Web
Detailed worksheet status is intentionally web-only:
- assigned / not assigned
- draft
- submitted
- late
- not submitted
- Paper / Digital
- reference code

This detail is hidden from both Print and Excel summary downloads.

## Work-score rule
The denominator is the number of worksheets actually assigned by the teacher, not the total number of ready-made templates.
