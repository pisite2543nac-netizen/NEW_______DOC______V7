# V16.9 Clean Dashboard

ลดเมนูซ้ำและรวมงานเป็น Flow:
- Sidebar เหลือ หน้าแรก / รายวิชา / โปรไฟล์ (+ ออกจากระบบเดิม)
- Admin Dashboard มี 6 ปุ่มใหญ่: การสอนและรายวิชา, นักศึกษาและสิทธิ์, งานคะแนนรายงาน, เช็คชื่อ, ระบบสอบ, ปีการศึกษาและระบบ
- Student Dashboard มี 6 ปุ่มใหญ่: รายวิชาทั้งหมด/ใส่ CODE, วิชาที่เรียนอยู่, งานของฉัน, เช็คชื่อ, ข้อสอบ, ข้อมูลของฉัน
- เมนูย่อยที่ใช้น้อยเปิดผ่าน Flow modal เท่านั้น ไม่กองอยู่ใน Sidebar
- V16.8 sequential unit lock ยังทำงานเหมือนเดิม
