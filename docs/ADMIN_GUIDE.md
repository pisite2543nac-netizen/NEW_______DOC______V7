# คู่มือ Admin — V15 FINAL

## 1. คำขอบัญชี

เปิดเมนู **คำขอบัญชี** ตรวจชื่อ รหัสนักศึกษา ชั้น/ห้อง และข้อมูลผู้สมัคร แล้วเลือกอนุมัติ/ไม่อนุมัติ/ระงับ บัญชีที่ยัง Pending ไม่สามารถเข้าถึงวิชาและใบงานได้

## 2. ลงทะเบียนรายวิชา

เมนู **อนุมัติรายวิชา** ใช้ตรวจคำขอของนักศึกษา เมื่อ Approved ผู้เรียนจึงถือเป็นสมาชิกวิชาและจะได้รับงานที่เผยแพร่ในวิชานั้น

## 3. ใบงาน

ภายในรายวิชาแยก **Paper** และ **Digital** ชัดเจน สามารถเลือกหลายใบและปล่อยพร้อมกัน กำหนดวันเปิด/กำหนดส่ง/ส่งช้า/ส่งซ้ำ/จำนวนครั้งในขั้นตอนเดียว

## 4. ตรวจงาน

Admin เท่านั้นที่เห็น Answer Key, Rubric, คะแนนและความคิดเห็น สามารถให้ Draft/Final grade ตาม UI ที่รองรับ ข้อมูลผู้เรียนจะไม่เห็นคะแนนจากฝั่ง User

## 5. สิทธิ์ส่งเพิ่ม

กำหนดวันหมดอายุ, allow late, allow resubmit และ extra attempts รายบุคคล ระบบ Final Submit ตรวจสิทธิ์จาก Server ทุกครั้ง

## 6. Attendance

Admin หรือหัวหน้าห้องที่ได้รับแต่งตั้งสามารถสแกน QR เปิด session และบันทึกมา/สาย/ขาด/ลา Admin สามารถแก้สถานะโดยมี Audit

## 7. Exam

สร้างข้อสอบ → ตั้งช่วงเวลา/ระยะเวลา/attempt → Publish ให้สมาชิก Approved ในวิชา → ตรวจข้อเขียน ผู้เรียนจะเห็นเพียงสถานะ ไม่เห็นคะแนน

## 8. Promotion

เตรียม Batch → ตรวจรายบุคคล/Bulk → promote/repeat/graduate/transfer/suspend/cancel → Approve Batch → Apply. ระบบบันทึก Academic History ก่อนเปลี่ยนข้อมูลปัจจุบัน

## 9. Reports

Export CSV ทำผ่าน Server/Edge Function เท่านั้นและบันทึก Audit Log
