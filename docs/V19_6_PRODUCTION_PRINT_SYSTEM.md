## เอกสารที่พิมพ์ได้
1. สรุปคะแนนทั้งห้อง A4 แนวนอน
2. รายงานผลรายบุคคล A4 แนวตั้ง
3. ตารางเช็กงาน 17 หน่วย A4 แนวนอน
4. สรุปการเข้าเรียน A4 แนวนอน
5. สรุปผลการสอบ A4 แนวนอน
6. ใบงานเปล่ารายหน่วย A4 พร้อมสีวิชา QR/Barcode
7. ชุดใบงานเปล่าทั้ง 17 หน่วย พร้อมหน้าปกและสารบัญหน่วย
8. ใบงานรายบุคคลพร้อม Barcode/QR สำหรับ Admin
9. ใบงานย้อนหลังของผู้เรียน เมื่อ Server อนุญาตตาม Deadline/Assignment จริง
10. สรุปสถานะงานรายบุคคลของผู้เรียน

## ความปลอดภัย
- ไม่พิมพ์ Answer Key ให้ผู้เรียน
- Personalized Paper ใช้ RPC ฝั่ง Server และ Token ที่ผูกกับผู้เรียน
- Late Paper Self Print ตรวจ Assignment, Digital Deadline และสถานะการส่ง Digital ฝั่ง Server
- การพิมพ์ไม่แก้คะแนนหรือข้อมูลธุรกรรมหลัก
- สีมี Fallback ใน Frontend เพื่อให้เอกสารยังแยกวิชาได้แม้ color_hex ขาดหาย
