# คู่มือผู้เรียน — V15 FINAL

## สมัคร

ใช้รหัสนักศึกษา รหัสผ่าน ข้อมูลชั้น/ห้อง/สาขา และถ่ายภาพจากกล้องหน้าสด เมื่อสมัครสำเร็จให้รอ Admin อนุมัติบัญชี

## ลงทะเบียนวิชา

หลังบัญชี Approved เลือกวิชาที่ต้องการและกดขอลงทะเบียน สถานะจะเป็น “รอ Admin อนุมัติ” เมื่อ Approved วิชาจะปรากฏใน Dashboard

## Digital Worksheet

เปิดใบงาน → อ่านกำหนดเวลา → ทำคำตอบ → ระบบบันทึกร่างถ้าเปิดใช้ → ตรวจทาน Preview → ยืนยันส่ง เวลา Server เป็นเวลาส่งจริง

หากใบงานปิดการ Copy/Paste ระบบจะเตือนให้พิมพ์คำตอบเอง ฟังก์ชันนี้เป็นมาตรการช่วยลดการคัดลอก ไม่ใช่การป้องกัน 100%

## Paper Worksheet

เปิด/พิมพ์ใบงาน A4 → ทำงาน → ส่งเอกสารตามวิธีที่ครูกำหนด → สแกน QR/Barcode หรือกรอกรหัสเพื่อยืนยัน Server จะตรวจสิทธิ์และเวลา

## คะแนน

หน้าผู้เรียนแสดงเฉพาะสถานะ เช่น ยังไม่ส่ง, ร่าง, ส่งแล้ว, ส่งช้า, รอตรวจ, ตรวจแล้ว, หมดเวลา ไม่แสดงคะแนน เกรด เฉลย Rubric หรือความคิดเห็นภายในของ Admin

## Attendance / Exam

ผู้เรียนดูสถิติ Attendance ของตนเองและทำ Exam ที่ได้รับมอบหมาย Exam มี Timer/Autosave/Auto-submit ตามเวลา Server และหน้าผู้เรียนไม่แสดงคะแนน
