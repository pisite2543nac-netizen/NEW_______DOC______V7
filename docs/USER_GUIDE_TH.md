# คู่มือใช้งาน DOC-FULL-NR V7

## ผู้ดูแลระบบ
1. เข้าระบบ
2. ห้องเรียน: เพิ่มห้อง/ปี/ภาคเรียน
3. รายวิชา: ตรวจ 13 วิชาเริ่มต้นหรือเพิ่มวิชาใหม่
4. ผู้ใช้งาน: สร้างบัญชีผู้เรียนด้วย Edge Function
5. ใบงาน: สร้าง Digital/Paper, กำหนดเวลา, คำถาม, เฉลย, Rubric
6. Publish: ใช้ RPC ฝั่งฐานข้อมูลเพื่อเผยแพร่
7. ตรวจงาน: เปิดงานที่ submitted/confirmed, ให้คะแนน/เกรด/ความคิดเห็น
8. รายงาน: Export CSV
9. Audit: ตรวจเหตุการณ์ระบบ

## ผู้เรียน
1. Login
2. ใบงานของฉัน
3. เปิดใบงาน > ตอบ > บันทึกร่าง
4. กดส่งงาน
5. หลังส่งแล้วระบบล็อกตามกติกาฝั่งฐานข้อมูล

## Paper
Admin เข้าใบงาน > พิมพ์/QR > Save PDF หรือพิมพ์กระดาษ
