DOC-FULL-NR V19.6 — PRODUCTION PRINT SYSTEM
วิทยาลัยเทคนิคนางรอง

สิ่งที่เพิ่ม
1) ศูนย์พิมพ์และสรุปผลสำหรับ Admin และ User
2) สีประจำวิชา 11 รายวิชา ใช้กับหัวเอกสาร/แถบวิชา/เลขหน่วย โดยพื้นที่เขียนยังเป็นสีขาว
3) สรุปคะแนนทั้งห้อง A4 แนวนอน: งาน 40 + จิตพิสัย 20 + กลางภาค 20 + ปลายภาค 20 + รวม + เกรด + ผ่าน/ไม่ผ่าน
4) รายงานผลรายบุคคล A4 แนวตั้ง
5) ตารางเช็กงาน 17 หน่วย A4 แนวนอน
6) สรุป Attendance A4 แนวนอน
7) สรุปผลการสอบ A4 แนวนอน
8) ใบงานเปล่า A4 พร้อมตราวิทยาลัย/รหัสเอกสาร/QR/Barcode เมื่อ Library พร้อม
9) ใบงานรายบุคคลพร้อม Barcode/QR และข้อมูลผู้เรียน
10) ผู้เรียนพิมพ์ Paper ย้อนหลังได้เฉพาะเมื่อ Server ตรวจสิทธิ์ผ่าน
11) รองรับ Print และ Save PDF

ความปลอดภัย
- เฉลย/Answer key ไม่ถูกนำไปพิมพ์ให้ผู้เรียน
- Personalized Paper ใช้ RPC ฝั่ง Server และ Token/Barcode ผูกผู้เรียน
- Late Paper Self Print ตรวจ assignment, deadline และสถานะ Digital ฝั่ง Server ก่อนออกเอกสาร
- การพิมพ์ไม่แก้คะแนนหรือข้อมูลธุรกรรมหลัก

หมายเหตุ
- ระบบ QR/Barcode มีข้อความอ้างอิงสำรองหาก Library ภายนอกโหลดไม่ได้ แต่การสแกนด้วยภาพต้องมี Library ที่เกี่ยวข้องพร้อมใช้งาน
- Migration Production สำหรับสีวิชาและ Print RPC ถูกออกแบบให้ idempotent/replace function ได้
