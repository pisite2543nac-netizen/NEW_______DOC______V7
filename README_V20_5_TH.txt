ระบบเช็คชื่อเข้าสายด้วยบาร์โค้ดครู + ระบบจัดกลุ่มห้องโดย Admin

1) เช็คชื่อปกติ
- 15 นาทีแรกยังใช้ Flow เดิม
- ครู/Admin หรือหัวหน้าห้องสแกน QR ประจำตัวนักศึกษา

2) เมื่อเกิน 15 นาที
- Backend ปิดการเช็คชื่อปกติ ไม่ให้สแกน QR นักศึกษาเป็น “สาย” แบบเดิม
- ครู/Admin เปิดรอบที่ปิดแล้วและกด “บาร์โค้ดเข้าสาย”
- ระบบสร้าง DOCNR-LATE token ชั่วคราว ผูกกับคาบเรียนจริง
- นักศึกษาเปิดหน้าเช็คชื่อบนโทรศัพท์ของตนเอง แล้วเปิดกล้องสแกนรหัสของครู
- ระบบตรวจสมาชิกห้อง + สมาชิกวิชา + อายุ token + เวลา Server แล้วบันทึกเป็น “มาสาย”
- มีถ่ายภาพบาร์โค้ดสำรองและกรอก Token สำรอง
- บันทึก Audit และ Notification

3) จัดกลุ่มห้องโดย Admin
- เป็นระบบแยกจาก Subject Room เดิม
- สร้างกลุ่ม/รหัสกลุ่ม/ปี/ภาค/ระดับ/แผนก/สาขา
- เลือกสมาชิกและจัดกลุ่มได้โดยไม่ลบประวัติวิชา งาน คะแนน
- เพิ่มสมาชิกทั้งกลุ่มเข้ารายวิชาได้
- เมื่ออนุมัติเข้าวิชา ระบบ reconcile Worksheet/Exam ที่เผยแพร่แล้ว

4) ระบบเดิมยังคงอยู่
Course CODE, 17 Units, 20-slide Teaching, Digital/Paper Worksheet, Attendance Summary, Gradebook, Exam 550 questions, Print Center, PWA, Special Activities, Promotion และ Adaptive Phone/Tablet/Desktop UX
