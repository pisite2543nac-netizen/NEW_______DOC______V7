REAL-DEVICE DEFECT REPRODUCED FROM USER VIDEO
- The phone recording showed V20.3 repeatedly returning from Admin Attendance Flow to Dashboard before the camera workflow could be reached.
- Root cause: the Admin route authorization set did not include the `attendance` feature subroute. navigateUnified() therefore replaced it with `dashboard`.
- V20.4 adds the authorized Admin attendance subroute, maps it back to the Attendance Hub for navigation state/back behavior, and adds a dedicated regression contract so this defect cannot silently return.
